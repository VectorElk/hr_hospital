HR Hospital

A hospital management addon for Odoo School with patients, doctors, visits, diseases, reports, and role-based access.

Highlights

  • Patient, doctor, visit, and condition management.
  • Calendar, list, pivot, graph, kanban, and search views.
  • Wizard-based visit reports and doctor PDF reports.
  • Role hierarchy: Patient → Intern → Doctor → Manager → Administrator.
  • Ukrainian translations for the module and disease classifier.

Security model

  • Patients can read only their own visits.
  • Interns can read and write their own visits.
  • Doctors can manage their own visits and intern visits.
  • Managers can read all visits.
  • Administrators can delete any module data when business rules allow it.

Installation

  1. Copy hr_hospital into your Odoo addons path.
  2. Update the apps list in Odoo.
  3. Install the module from Apps.
  4. Use the bundled upgrade_addon.sh script for local upgrades if needed.

Included UI

  • Main menu and model actions.
  • Doctor report available from the Print menu.
  • Visit report wizard available from list and form views.
  • Module icon packaged for the Odoo Apps page.

Built for Odoo 19.0 and aligned with the module documentation and security tasks in this repository.
